# The Agent Rewrote the Demo

Entry for make.fun's "The joke about the demo" bounty ($35, escrowed).

A Node 22 program (`main.ts`, standard library only) that writes one
one-line joke about working beside AI coding agents to `/output/entry.txt`.

The joke: "The agent rewrote the entire demo five minutes before curtain, so now we are betting our careers on code written by a system that has never felt fear."

Run: `node main.ts` (writes to `$MAKEFUN_OUTPUT_DIR/entry.txt`, default `/output`).
